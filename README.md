## Descripción del Proyecto
UrbanRoute es una herramienta de software desarrollada en Java que permite modelar, analizar y simular la red de transporte público urbano como un grafo ponderado. El sistema facilita la búsqueda de rutas de tiempo mínimo, la identificación de estaciones clave (*hubs*) y la detección de zonas aisladas ante interrupciones en el servicio, apoyándose en un TDA Hash Table para la gestión e indexación eficiente de datos en $O(1)

## Ejecución

Abrir la carpeta `ProyectoEstrucDatos` en NetBeans y ejecutar el proyecto. Las librerías de GraphStream se encuentran en `ProyectoEstrucDatos/lib`. Al iniciar se carga el archivo maestro `datos/metro_caracas.csv`.
