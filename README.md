# Proyecto---Estructura-de-Datos

## Fundamentación Técnica de Elementos Adicionales

Con el objetivo de mantener el código fuente limpio y legible, las APIs, librerías externas (como **Swing/AWT** y **GraphStream**), estructuras de entrada/salida y características avanzadas del lenguaje Java que exceden el alcance teórico visto en clase han sido señaladas directamente en los archivos `.java` mediante indicadores secuenciales con el formato `// *N` (desde `// *1` hasta `// *48`).

Cada indicador cuenta con su respectiva explicación técnica, fragmento de referencia y enlace a la documentación oficial de Oracle o de la librería correspondiente en el documento adjunto:

* 📄 **[Ver Fundamentación Técnica Completa (`FUNDAMENTACION_TECNICA.md`)](./FUNDAMENTACION_TECNICA.md)**

> **Nota:** Las clases que implementan exclusivamente Programación Orientada a Objetos básica o estructuras de datos vistas en clase (`Arista`, `EntradaHash`, `Estacion`, `Nodo`, `ListaEnlazada`, `Grafo`, `ResultadoRuta` y `Vertice`) no contienen indicadores adicionales salvo en los puntos donde introducen sintaxis específica de Java ya documentada.
