# UrbanRoute - Optimización y Análisis de Redes de Transporte Multimodal

Aplicación en Java (NetBeans/Ant) que modela una red de transporte urbano como un grafo ponderado, indexa las estaciones en una tabla hash propia y permite calcular rutas de menor tiempo, detectar subredes aisladas e identificar hubs de transferencia, con visualización mediante GraphStream.

**Asignatura:** Estructuras de Datos (BPTSP06)

**Integrantes:** Elohym Casais, Maria Andreina Piñero y Alex Sisitiaga.

**Repositorio:** https://github.com/jecasais/Proyecto---Estructura-de-Datos

## Ejecución

Abrir la carpeta `ProyectoEstrucDatos` en NetBeans y ejecutar el proyecto. Las librerías de GraphStream se encuentran en `ProyectoEstrucDatos/lib`. Al iniciar se carga el archivo maestro `datos/metro_caracas.csv`.
